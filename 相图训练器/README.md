# 相图训练器 · 材料科学基础（胡庚祥 第3版）

一个给手机用的离线单文件网页，专门练「看相图」：点哪讲哪、两相区自动算杠杆定律、相组成物和组织组成物分开讲。

## 怎么用

直接用手机或电脑浏览器打开根目录的：

**`材料科学基础-相图训练器.html`**

单文件、无外部依赖、不联网也能用。可以发到微信里用手机浏览器打开，也可以放到网盘里随时点开。

## 四个模块

| 模块 | 内容 |
| --- | --- |
| 铁碳相图 | 全图 / 看钢（聚焦 620–1010℃ 相变区）/ 看铸铁。点任意位置读出：相区、相组成物、组织组成物、室温组织、杠杆定律、冷却过程 |
| 二元相图 | 匀晶 Cu-Ni、共晶 Pb-Sn、包晶 Pt-Ag。两相区自动画连接线并按杠杆定律算两相比例 |
| 三元成分 | 可拖动的成分三角形，实时读出 A/B/C 三个组元含量，并画出三条读数辅助线；附三元共晶投影示意 |
| 刷题 | 37 道题，覆盖相区识别、杠杆定律、特征点、组织判断、二元基础、三元基础；错题自动进错题本（存在浏览器本地） |

## 设计上的几个点

- **手机滚动不被图吃掉**：相图用 `touch-action: pan-y`，在图上下滑是翻页、左右滑才改成分；图下方另有「含碳量 / 温度」滑杆和一键跳到详解的按钮，任何情况下都能看到下面的内容。页面顶部有一条滚动进度条（手机浏览器默认不显示滚动条）。
- **刷题有总数和进度**：题头显示「共 37 题 · 已答 x · 答对 y」并配进度条，每道题右上角也有「第 x / 37 题」。
- **铁碳相图按教材第3版的数据**：共析点 S(0.77%, 727℃)、共晶点 C(4.3%, 1148℃)、E 点 2.11%、P 点 0.0218%、包晶 1495℃。
- **相组成物与组织组成物分开显示**：727℃ 以下所有钢的相组成物都是 α+Fe₃C，但组织可能是铁素体+珠光体、珠光体+二次渗碳体……这正是考试最容易混的地方。
- **杠杆定律只出现在两相区**：单相区不显示，避免误导。
- **点击命中按相区规则判定**，不是靠多边形硬猜，所以边界附近也能给出合理结果。

## 源码结构（想改的话）

```
相图训练器/
├─ build.js            # 打包：把 src/ 内联成一个 HTML
├─ src/
│  ├─ index.html       # 页面骨架
│  ├─ style.css        # 样式（移动端优先）
│  ├─ core.js          # 相图数据 + 相区判定 + 杠杆定律 + 冷却分析（无 DOM，可单独测）
│  ├─ app.js           # SVG 绘制与交互
│  └─ questions.js     # 题库
└─ test/
   ├─ core.test.js     # 核心逻辑自测（node test/core.test.js）
   ├─ shots.js         # 无头 Chrome 各页截图（需先启动 --remote-debugging-port=9333）
   └─ e2e.js           # 交互回归
```

改完源码后重新打包：

```bash
node 相图训练器/build.js
```

## 自测

```bash
node 相图训练器/test/core.test.js
```

覆盖相区判定、杠杆定律、组织组成物、冷却关键温度、二元读写、三元重心坐标等 100 多项断言。
